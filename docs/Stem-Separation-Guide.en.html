Live RAM preview

Settings → Live RAM preview is enabled by default. Select Remixed, press Play and change EQ, stereo DSP, Drum Lab, stem gains, Mute/Solo or DrumSep selection while listening. A persistent CPU worker processes 200 ms PCM blocks with a bounded 256 MiB cache and short parameter crossfades. It does not write preview WAV files. A/B switching preserves position and playback state.

Preview is 48 kHz float32 before export mastering; it is not loudness-matched to the original. Computing and audio buffers add latency. Sub synthesis and trigger detection use short context and may differ from full-track export. Export renders the complete file from source with current settings, selected format and LUFS/true-peak processing. GPU/VRAM is reserved for model inference, not live DSP. Turn off Live RAM in Settings to restore file-based previews if needed. Waveform comparison is computed in RAM on request.

1. Start a project

  1. Open Settings, choose your Python engine and FFmpeg. Use Download and install FFmpeg if needed; the package checksum is verified before installation.
  2. Choose New Project, then Open local audio or paste a public Suno song URL. If Suno refuses a download, open the song on Suno and download through the service, then import the file.
  3. The bottom player is shared by the whole song. Select Original or Remixed, then Play. Pause, Stop and Repeat apply to that version. Drag a waveform or the seek bar to move through the song.

Settings and history use the existing SQLite database in %LOCALAPPDATA%\StemForge. Renaming the application does not erase earlier projects. JSON project files reference audio on disk, so keep the session folder when backing up a project.

Choose a processing mode

  • Option 1 — Transient / Tonal + Mid/Side is the default. It estimates transient and sustained content directly in stereo audio. Adjust impact and tonal mud/harshness, then listen to Remixed. This is not an isolated drum stem and may affect vocals and other instruments.
  • Option 2 — Impact + Sub shapes estimated impact and synthesizes low end. It cannot recover the original missing sub-bass.
  • Stems / Refix uses the separated-instrument workflow below. The stem mixer and Drum Lab contribute only in this mode.

2. Separate and remix stems

  1. Select Stems / Refix. Choose a four- or six-stem model and Auto/CPU/CUDA, then Separate stems. Initial model downloads need Internet.
  2. For the cascade, use Two-stage separation: SW → DrumSep. It first separates six instrument stems with BS-RoFormer SW, then splits the Drums stem with DrumSep MDX23C into Kick, Snare, Toms, Hi-hat, Ride and Crash.
  3. Valid existing results are reused. If only stage two is missing, the cascade resumes there. A changed source/model or missing output files require the affected stage to run again.
  4. Set gain, Mute and Solo for Bass, Vocals, Other, Guitar and Piano as available. After DrumSep, select drum lanes and set each lane's gain beneath the shared waveform.
  5. Apply Drum Lab processing, optional sample layering, then listen using Remixed in the bottom player.
Final stem signal path:
Selected DrumSep lanes + individual samples → per-lane gain → Drum Lab → parent Drums gain/mute/solo → add other instrument stems with their gains → Refix → export mastering.
The reconstructed drum bus replaces the original Drums stem. The original full stereo track is never added on top of the stems. If no drum lanes are selected, only the other instrument stems remain.

The six drum waveforms share one timeline and use different colors. Selecting a drum controls both its contribution to the remix and waveform visibility. Individual gains also affect its displayed waveform. Original/processed comparison checkboxes only change display, not the audio.

3. Know the drum kit

Kick / Bass drum

The large pedal-played drum. It anchors low-end pulse and often interacts strongly with bass. Increase gain or layer a kick sample gradually; check the low end in the whole mix.

Snare

A sharp drum with wires under the lower head. Commonly carries the backbeat and quiet ghost notes. High thresholds can remove those soft notes.

Toms

Pitched drum shells used for fills and rolls. This app combines tom hits into one lane and one MIDI note; it does not identify individual tom sizes.

Hi-hat

A pair of cymbals controlled by a pedal. Fast patterns can be lost with a long retrigger interval. Open and closed hi-hats currently share one MIDI mapping.

Ride

A larger cymbal used for a sustained rhythmic pattern, with distinct bow and bell sounds. Listen for long tails before adding compression or samples.

Crash

An accent cymbal with a wide, sustained wash. Avoid treating every part of its decay as a new hit. Keep the balance with vocals and other high-frequency instruments.

4. Drum Lab controls

ControlMeaning
TransientBoosts or reduces attack across the drum bus, including cymbals. It is not a volume percentage.
MultibandBlends three-band compression, with crossovers at 180 Hz and 4 kHz. The compressed branch uses −24 dB threshold and 3:1 ratio.
ParallelBlends heavy compression (−28 dB, 8:1, +6 dB makeup) for body and density. It can also raise background sounds.
Sample amountAt 0%, sample processing is disabled. Layer mode adds samples while preserving the lane. Replace attenuates the original lane as the sample mix increases. A lane without a replacement sample retains its original sound.
Trigger sensitivity / thresholdSensitivity is relative to strong hits; the dBFS threshold is an absolute gate. Raise sensitivity or lower the threshold for ghost notes, then check for false triggers.
Retrigger intervalMinimum spacing between hits of the same type. At 120 BPM, 1/32 notes are 62.5 ms apart. A 70 ms interval can miss them.
Cross-band rejectionSuppresses competing frequency-band onsets when using an unsplit drum stem. It is bypassed when valid DrumSep lanes are available.
Preserve dynamics100% retains relative hit strength; 0% makes all triggered samples full-strength. It cannot restore rejected hits.
Round robin / velocityRound robin cycles sample files. Velocity selects from soft to loud in file-name order. Choose up to eight files per drum. One file cannot supply multiple variations.
Studio / ElectronicBuilt-in synthesized Kick/Snare/Hi-hat. Toms/Ride/Crash need DrumSep lanes and your own samples.

Genre suggestions are starting points, not automatic analysis. Selection previews the twelve settings; Apply changes the controls. Save settings… stores a named preset in Suggestions, optionally as the default for newly imported tracks. Custom sample paths and MIDI mapping stay with each project.

5. MIDI, BPM and lyrics

Detect BPM / key runs only when clicked. The alternative backend is the MIT-licensed libraz/bpm-detector analysis subset. It examines up to three 30-second windows. BPM may be half/double and key may vary between sections. Silence, weak evidence, failures or a 90-second timeout are skipped; audio processing and export remain available. Scores are not probabilities.

Use BPM for MIDI updates MIDI export tempo only. It does not stretch audio or quantize hits. Drum MIDI uses channel 10 and transient detection on the separate lanes. Reset mapping restores Kick 36, Snare 38, Toms 45, Hi-hat 42, Ride 51 and Crash 49 while keeping BPM.

On the Vocals stem, open Lyrics…, choose a Whisper model and automatic or explicit language, then Extract lyrics. Listen to each line, edit text/timestamps, and export LRC or SRT. UTF-8 preserves Vietnamese and other Unicode text. Singing may be misrecognized; review before export.

6. Export and verify

EXPORT MIX renders the chosen processing mode as WAV or FLAC with the selected sample rate, bit depth and optional loudness target. WAV supports 16/24-bit PCM and 32-bit float; FLAC supports 16/24-bit. Upsampling does not recover detail lost in a source MP3.

EXPORT STEMS uses stem gains and the reconstructed Drum Lab bus, without master Refix/loudness. Export drum lanes… exports selected DrumSep lanes with individual gains, before group effects. Listen to the final mix for low-end balance, harsh cymbals, missed hits and clipping before delivery.

7. Interface language and extensions

Settings → Application language → Tiếng Việt or English → Save, then restart. Vietnamese is the default. To add a language, copy Languages/en.json, change code and name, and translate the values in strings. Keep source keys, placeholders and format specifiers intact. Save UTF-8 beside the application or in %LOCALAPPDATA%\StemForge\Languages, restart and select it. Missing translations fall back to Vietnamese.

Song names, lyrics, custom preset names, existing history and third-party logs are preserved. See Languages/README.md for the catalog format. The embedded guide has Vietnamese and English editions.

Continuous A/B, stem audition and collapsible steps

Switch Original / Remixed while playing to continue at the current position. A paused player stays paused. Live RAM applies changes within the PCM stream after a short buffer delay; pressing Stop cancels pending playback. If Live RAM is disabled, the old file-preview method renders the remix while the current audio continues. A/B is not loudness-matched.

Use the ▶ button on each instrument stem to audition that stem with its gain, bypassing mixer Mute/Solo, Drum Lab and master effects. Pause/Stop remain in the shared bottom transport. Select Original / Remixed and Play to return to the whole song.

The small arrow at the lower-right corner of each step hides or expands its content without changing settings or playback. Collapsed states are stored in SQLite.

Direct Suno lyrics

Open Lyrics, then Get lyrics from Suno (Suno sign-in required). Sign in in the separate window and fetch actual timestamps without Whisper. Review lyrics and timing before LRC/SRT export; incomplete timing needs editing, or export TXT.

Playback, seeking and repeating automatically select and scroll to the matching line, highlighted blue with white text. Gaps have no selected line. Editing a cell suspends automatic selection. Delete all stops playback and clears the editor; save the draft or close the window to persist the empty lyrics. Audio files are retained.

Settings and Light/Dark are now at the top-right beside Guide/About; History follows Save project. After a successful audio, stems, MIDI or lyrics export, Export folder appears in the bottom bar and opens the latest completed output.
